Add your Cala API key

Investor Check gets its answers from Cala. To use it you need your own Cala key. It takes about a minute, and you only do it once on this device.

  1. 1

    Open Cala

    Go to console.cala.ai (opens in a new tab) and sign up or log in.

  2. 2

    Copy your API key

    In the Cala console, create an API key and copy it. It is a long line of letters and numbers.

  3. 3

    Paste it here

    Your key is saved in this browser only. It is sent to Cala to get your answers and is not stored on our server.

A key is already saved in this browser. Paste a new one above to replace it.
